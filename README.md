**Project Logic**
This simple program is a small school registration management system that takes teacher and student applicants. Methods and condition statements are implemented
to display and manipulate student and teacher info. **Please Note: When prompted to change teacher salary, select 1 as only one teacher is 'registed'. Entering another number will go to the default case.**
